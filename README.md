
# M-Pesa Data Analysis: Financial Inclusion in Kenya

## Overview
This project analyzes the impact of mobile money (M-Pesa) on financial inclusion and economic development in Kenya.

## Data Sources
- World Bank (GDP, poverty)
- FinAccess Surveys (financial inclusion)
- Central Bank of Kenya (mobile money statistics)
- Safaricom reports

Note: I interpolated the missing yearly data points from the available data. 

## Key Findings
- Financial inclusion among Kenyans from the formal and informal sectore increased from 26.7% (2006) to 84.8% (2024)
- Mobile money adoption reached 40 million users within 22 years. (It is important to note that Kenya's population is around 50 to 60 million people)
- Strong correlation between mobile money usage and financial inclusion
